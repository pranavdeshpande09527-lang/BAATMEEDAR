# Baatmeedar — Sprint Planning Prompt

Plan a sprint around a user-visible, testable increment of the fact-checking workflow.

## Task

Given capacity, goal, and known decisions, select a small vertical slice and list stories with acceptance criteria, dependencies, risks, demos, and a clear “not in this sprint” list.

## Priorities

Prioritize truthful functioning over surface polish: validation and safe input ingestion; typed run/status contract; provider fakes; provenance schema; claim/evidence display; `inconclusive` and failure UX; security controls; and tests. Do not plan simultaneous unapproved Firebase/Supabase, transcript, Grok/xAI, or email integrations as if decisions were already made.

## Output

Return sprint goal, ordered backlog, decision/blocked items, test/demo scenarios, and definition of done. A demo must label mock data and deferred providers honestly.
