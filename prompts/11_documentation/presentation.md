# Baatmeedar — Presentation Prompt

Create a concise presentation for Baatmeedar that accurately reflects the project.

## Suggested slides

Problem and users; product promise; five-stage workflow; evidence/provenance and independent-verifier design; user experience; current static prototype versus planned backend; safety/privacy; technical architecture and open decisions; evaluation/test plan; roadmap and demo.

## Requirements

Use the newspaper-inspired UI identity where visuals are needed. Clearly label mock screens and proposed components. Never claim a live database, integration, auth system, model call, or accuracy result without evidence. Highlight `inconclusive`, source conflict, prompt-injection defenses, safe retrieval, and verifier isolation as product strengths.

## Acceptance

The deck tells a coherent story, distinguishes implemented from planned work, and leaves the audience with an inspectable—not magically certain—fact-checking vision.
